Report the patterns in hangar's usage log where callers waste effort

Usage: hangar self usage [OPTIONS]

Options:
      --since <DURATION>        How far back to read the usage log, such as 12h, 7d or 2w [default: 7d]
      --log <FILE>              Read this usage log instead of the tool's own
      --exclude-program <NAME>  Leave out the runs that a program with this name marked, such as flightdeck
  -h, --help                    Print help (see more with '--help')

Examples:
  hangar self usage

Effects: read-only, closed-world.
Global flags: --json, --fields <FIELD>, --full, --no-input. `hangar self usage --help` describes them.
