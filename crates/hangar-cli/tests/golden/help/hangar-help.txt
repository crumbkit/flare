Serve a board's pages and bindings on this machine, open them in a browser, publish pages and save bindings

Usage: hangar [OPTIONS] <COMMAND>

Verbs
  serve     Serve a board's pages and bindings on this machine until Ctrl-C
  open      Open the running server's index, a page or a binding in a browser
  publish   Publish a new version of a page from an HTML or Markdown file
  bind      Save a binding that fills a page's slots with records

Commands
  commands  Explore hangar's commands
  self      Review hangar's own use

Options:
      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --long
          Add the long columns after the compact ones. The default prints only the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Topics: exit-codes. `hangar help <TOPIC>` prints one.
