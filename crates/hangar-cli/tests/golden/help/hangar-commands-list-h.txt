List a branch of hangar's commands with their arguments and examples

Usage: hangar commands list [OPTIONS] [PATH]...

Arguments:
  [PATH]...  The names of the commands below the root that lead to the branch, such as `books list`

Options:
      --limit <N>  Print at most this many rows [default: 25]
      --all        Print every row
  -h, --help       Print help (see more with '--help')

Examples:
  hangar commands list
  hangar commands list serve

Effects: read-only, closed-world.
Global flags: --json, --fields <FIELD>, --full, --no-input. `hangar commands list --help` describes them.
Next: hangar commands list --help explains each column.
