Serve a board's pages and bindings on this machine until Ctrl-C

Usage: hangar serve [OPTIONS]

Options:
      --board <DIR>           The board's directory; without it, the nearest directory at or above the current one that holds .board/board.json
      --board-program <PATH>  The board program; without it, HANGAR_BOARD, then the first board on PATH
      --port <N>              The launch host's port on 127.0.0.1; 0 picks a free port [default: 0]
      --config <PATH>         The config file; without it, $XDG_CONFIG_HOME/hangar/config.json or ~/.config/hangar/config.json
      --idle-exit <DURATION>  Stop after this long without a request, such as 30m or 8h [default: 8h]
  -h, --help                  Print help (see more with '--help')

Examples:
  hangar serve
  hangar serve --board ../notes --idle-exit 1h

Effects: additive, not idempotent, closed-world.
Global flags: --json, --fields <FIELD>, --full, --no-input. `hangar serve --help` describes them.
Next: hangar serve --help explains each column.
