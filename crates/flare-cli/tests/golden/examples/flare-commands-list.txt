PATH                  ABOUT
flare                 Serve a board's pages and bindings on this machine, open them in a browser, publish pages and save bindings, and share files through a flare server
flare serve           Serve a board's pages and bindings on this machine, or its pages behind a TLS proxy, until Ctrl-C
flare open            Open the running server's index, a page or a binding in a browser
flare publish         Publish a new version of a page from an HTML or Markdown file
flare bind            Save a binding that fills a page's slots with records
flare login           Sign in to a flare server and keep its token in the Keychain
flare logout          Revoke this computer's flare token and delete it
flare share           Share a Markdown file with named people, or as a response to flares
flare show            Show one version of a share you can open, or its latest
flare grant           Grant an existing share to more people
flare shares          List your shares or the shares granted to you
flare activity        List the responses to flares since a cursor, oldest first
flare search          Search the shares you can open, newest first
flare metrics         Count the metric lines in a flare server's log, by day
flare commands        Explore flare's commands
flare commands list   List a branch of flare's commands with their arguments and examples
flare schemas         Explore the JSON documents that flare prints
flare schemas list    List the JSON documents that flare prints, with a description of each
flare schemas show    Print the JSON Schema of each document
flare skills          Manage flare's agent skill
flare skills install  Install flare's skills into each agent skills directory that exists
flare skills check    Check that each installed copy of flare's skills matches this flare
flare skills print    Print flare's skill
flare self            Review flare's own use
flare self usage      Report the patterns in flare's usage log where callers waste effort
