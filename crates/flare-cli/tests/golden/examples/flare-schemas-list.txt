ID                      KIND    FORM      DESCRIPTION
flare/failure/v1        output  document  The document that a command prints on standard output when it fails with --json.
flare/serve/v1          output  document  The board a server served and why it stopped.
flare/open/v1           output  document  The page, binding or index that the browser opened.
flare/publish/v1        output  document  The page that was published, with its new version.
flare/bind/v1           output  document  The binding that was saved and the page version it is pinned to.
flare/login/v1          output  document  The server, the person and the label of the token that the Keychain now holds.
flare/logout/v1         output  document  The server and the label of the token that was revoked and deleted.
flare/share/v1          output  document  The share, its latest version, the people it is granted to and the flares it responds to, or what a dry run checked.
flare/show/v1           output  document  One version of a share the caller can open: its title, owner, the caller's role, its number and its Markdown.
flare/grant/v1          output  document  The share, the people this grant added and the flares it now responds to.
flare/revoke/v1         output  document  The share and the grants this command ended.
flare/grants/v1         output  document  The grants of a share to people, teams and everyone, dormant grants first.
flare/teams-create/v1   output  document  The team that was created, with you as its owner and first member.
flare/teams-add/v1      output  document  The team, its member count and the people this command added.
flare/teams-remove/v1   output  document  The team, its member count and the people this command removed.
flare/teams-list/v1     output  document  The teams you belong to, by name.
flare/teams-show/v1     output  document  The members of a team you belong to, in address order.
flare/teams-delete/v1   output  document  The deleted team. Its grants stay dormant and its name is never used again.
flare/shares/v1         output  document  The caller's shares, or the shares granted to the caller, newest first, and the cursor of the shares that follow.
flare/activity/v1       output  document  The responses to the named flares, oldest first, and the cursor of the next call.
flare/metrics/v1        output  document  The count of each Flare metric on each day in UTC, the total of each metric, and the lines read and skipped.
flare/commands-list/v1  output  document  One branch of the tool's commands with their arguments, examples and columns.
flare/schemas-list/v1   output  document  The JSON documents that the tool prints, with a description of each.
flare/schemas-show/v1   output  document  The JSON Schema of each document id given.
flare/self-usage/v1     output  document  The patterns in the usage log where callers waste effort, and a summary of the runs read.
