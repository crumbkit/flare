Add people to a team you own

Usage: flare teams add [OPTIONS] --with <PERSON> <NAME>

Arguments:
  <NAME>
          The team's name

Options:
      --with <PERSON>
          The people, repeated or separated by commas: each an address, or a name the server resolves

      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  flare teams add design --with mei@example.org,jo@example.org
          Add two people to the team design

Columns:
  team     The team's name.
  members  How many members the team has now.
  changed  The addresses added or removed; one already present, or already absent, is left out.

Effects: additive, not idempotent, closed-world.
