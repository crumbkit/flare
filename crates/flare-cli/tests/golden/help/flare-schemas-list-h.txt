List the JSON documents that flare prints, with a description of each

Usage: flare schemas list [OPTIONS]

Options:
      --limit <N>  Print at most this many rows [default: 25]
      --all        Print every row
  -h, --help       Print help (see more with '--help')

Examples:
  flare schemas list

Effects: read-only, closed-world.
Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `flare schemas list --help` describes them.
