Usage: flare reply [OPTIONS] --flare <FLARE> <--body <TEXT>|--body-file <FILE>> <COMMENT>

Arguments:
  <COMMENT>
          The comment to reply to, which is not itself a reply

Options:
      --flare <FLARE>
          The flare the comment is on

      --body <TEXT>
          The text, 1 to 8,000 characters

      --body-file <FILE>
          A file that holds the text, which is how to send more than one line

      --key <KEY>
          The key that makes a repeat of this call write nothing; without it, a new random key

      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  flare reply 8d1f0c2a9b7e4c53a6f20e1d4b9c7a85 --flare 3f9c0a17e2b44d6f8a1c5b7e9d20f4a6 --body 'Yes, ship it'
          Reply to a comment

Columns:
  id       The comment's or reply's id.
  flare    The flare it is on.
  parent   The comment a reply answers; absent for a comment.
  author   The author's identifier.
  at       When it was written, in RFC 3339 UTC.
  edited   When its text last changed, in RFC 3339 UTC; absent when it never did.
  deleted  Whether its author deleted it.
  body     Its text; absent once deleted.

Effects: additive, not idempotent, closed-world.
