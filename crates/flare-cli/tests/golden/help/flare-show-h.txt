Show one version of a share you can open, or its latest

Usage: flare show [OPTIONS] <ID>

Arguments:
  <ID>  The share to show

Options:
      --version <N>  The version to show, a number from 1; without it, the latest
  -h, --help         Print help (see more with '--help')

Examples:
  flare show 3f9c0a17e2b44d6f8a1c5b7e9d20f4a6
  flare show 3f9c0a17e2b44d6f8a1c5b7e9d20f4a6 --version 1

Effects: read-only, closed-world.
Children: The version's Markdown follows the share, one line of text for each line of the file. An HTML share prints a line that says so instead.
Global flags: --json, --fields <FIELD>, --full, --no-input. `flare show --help` describes them.
Next: flare show --help explains each column.
