Publish a page version from an HTML or Markdown file

Usage: flare publish [OPTIONS] --name <NAME> <FILE>

Arguments:
  <FILE>  The page's file: .html for HTML, .md for Markdown

Options:
      --name <NAME>           The page's name, one segment of lowercase letters, digits and dashes
      --slots <FILE>          A JSON file that lists the page's slots
      --board <DIR>           The board's directory; without it, the nearest directory at or above the current one that holds .board/board.json
      --board-program <PATH>  The board program; without it, FLARE_BOARD, then the first board on PATH
      --dry-run               Report what the command would change, and change nothing
  -h, --help                  Print help (see more with '--help')

Examples:
  flare publish card.html --name task-card --slots slots.json
  flare publish card.md --name task-card --dry-run

Effects: additive, not idempotent, closed-world.
Global flags: --json, --fields <FIELD>, --full, --no-input. `flare publish --help` describes them.
