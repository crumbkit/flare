Serve a board's pages and bindings on this machine, open them in a browser, publish pages and save bindings, and share files through a flare server

Usage: flare [OPTIONS] <COMMAND>

Verbs
  serve     Serve a board's pages and bindings on this machine, or its pages behind a TLS proxy, until Ctrl-C
  open      Open the running server's index, a page or a binding in a browser
  publish   Publish a new version of a page from an HTML or Markdown file
  bind      Save a binding that fills a page's slots with records
  login     Sign in to a flare server and keep its token in the Keychain
  logout    Revoke this computer's flare token and delete it
  share     Share a Markdown file with named people, or as a response to flares
  show      Show one version of a share you can open, or its latest
  grant     Grant an existing share to more people
  shares    List your shares or the shares granted to you
  activity  List the responses to flares since a cursor, oldest first
  metrics   Count the metric lines in a flare server's log, by day

Commands
  commands  Explore flare's commands
  schemas   Explore the JSON documents that flare prints
  skills    Install flare's agent skill
  self      Review flare's own use

Options:
      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --long
          Add the long columns after the compact ones. The default prints only the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Topics: exit-codes. `flare help <TOPIC>` prints one.
