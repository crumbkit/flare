Revoke this computer's flare token and delete it

Usage: flare logout [OPTIONS]

Options:
      --yes
          Proceed without asking for confirmation

      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  flare logout
          Revoke this computer's token and delete it from the Keychain

Columns:
  server  The server's origin.
  label   The label of the revoked token.

Effects: destructive, not idempotent, closed-world.
