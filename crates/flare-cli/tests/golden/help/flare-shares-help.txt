List your shares or those granted to you

The server lists at most 500 shares in one answer. A list cut short names the next call with --cursor, which resumes the list after the last share printed, and --all follows the cursor until the list ends.

Usage: flare shares [OPTIONS]

Options:
      --with-me
          List the shares granted to you in place of your own

      --everyone
          With --with-me, also list the shares open to everyone signed in

      --cursor <CURSOR>
          List the shares after this cursor, which an earlier flare shares printed

      --limit <N>
          Print at most this many rows, up to 500
          
          [default: 50]

      --all
          Print every row

      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  flare shares
          List your shares, newest first

  flare shares --with-me --limit 20
          List the 20 newest shares granted to you

  flare shares --with-me --cursor fs1.AQAAAABpJIEAqqqqqqqqqqqqqqqqqqqqqg
          List the shares granted to you after the cursor an earlier call printed

Columns:
  id       The share's id.
  title    The share's title.
  owner    The owner's identifier.
  role     The caller's role: `owner`, `admin` or `reader`.
  version  The latest version.
  created  When it was created, in RFC 3339 UTC.

Effects: read-only, closed-world.
