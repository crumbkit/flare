Explore the JSON documents that flare prints

Usage: flare schemas [OPTIONS] <COMMAND>

Commands:
  list  List the JSON documents that flare prints, with a description of each
  show  Print the JSON Schema of each document

Options:
  -h, --help  Print help (see more with '--help')

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `flare schemas --help` describes them.
Next: flare schemas <COMMAND> -h
