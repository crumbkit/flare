Manage a hosted site's image files

Usage: flare files [OPTIONS] <COMMAND>

Commands:
  sweep  Delete the image files that no version lists from the hosted site's bucket

Options:
  -h, --help  Print help (see more with '--help')

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `flare files --help` describes them.
Next: flare files <COMMAND> -h
