Create a team that you own, with you as its first member

Usage: flare teams create [OPTIONS] <NAME>

Arguments:
  <NAME>  The team's name: 1 to 40 lowercase letters, digits and dashes

Options:
  -h, --help  Print help (see more with '--help')

Examples:
  flare teams create design

Effects: additive, idempotent, closed-world.
Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `flare teams create --help` describes them.
Next: flare teams create --help explains each column.
