Serve a board's pages and bindings on this machine, open them in a browser, publish pages and save bindings, and share files through a flare server

Usage: flare [OPTIONS] <COMMAND>

Verbs
  serve           Serve a board's pages and bindings, locally or behind a TLS proxy, until Ctrl-C
  open            Open the running server's index, a page or a binding in a browser
  publish         Publish a page version from an HTML or Markdown file
  bind            Save a binding that fills a page's slots
  login           Sign in to a flare server and keep its token in the Keychain
  logout          Revoke and delete this computer's token
  share           Share a Markdown file with people, or as a response to flares
  show            Show one version of a share you can open, or its latest
  grant           Grant an existing share to more people
  shares          List your shares or the shares granted to you
  activity        List responses and comments since a cursor
  comments        List a flare's comments and replies
  comment         Comment on a flare
  reply           Reply to a comment
  comment-edit    Edit a comment or reply you wrote
  comment-delete  Delete a comment or reply you wrote
  metrics         Count the metric lines in a flare server's log, by day

Commands
  commands        Explore flare's commands
  schemas         Explore the JSON documents that flare prints
  skills          Manage flare's agent skill
  self            Review flare's own use

Options:
  -h, --help     Print help (see more with '--help')
  -V, --version  Print version

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `flare --help` describes them.
Topics: exit-codes. `flare help <TOPIC>` prints one.
