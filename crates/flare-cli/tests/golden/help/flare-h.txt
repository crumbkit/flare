Serve a board's pages and bindings on this machine, open them in a browser, publish pages and save bindings

Usage: flare [OPTIONS] <COMMAND>

Verbs
  serve     Serve a board's pages and bindings on this machine, or its pages behind a TLS proxy, until Ctrl-C
  open      Open the running server's index, a page or a binding in a browser
  publish   Publish a new version of a page from an HTML or Markdown file
  bind      Save a binding that fills a page's slots with records

Commands
  commands  Explore flare's commands
  self      Review flare's own use

Options:
  -h, --help     Print help (see more with '--help')
  -V, --version  Print version

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `flare --help` describes them.
Topics: exit-codes. `flare help <TOPIC>` prints one.
