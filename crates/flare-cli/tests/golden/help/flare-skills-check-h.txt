Check that each installed copy of flare's skills matches this flare

Usage: flare skills check [OPTIONS]

Options:
      --dir <DIR>  Check this skills directory in place of the agent skills directories
  -h, --help       Print help (see more with '--help')

Examples:
  flare skills check

Effects: read-only, closed-world.
Rows: the default text lists only the rows that report a problem or a warning, and --long, --fields or --json lists every row.
Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `flare skills check --help` describes them.
Next: flare skills check --help explains each column.
