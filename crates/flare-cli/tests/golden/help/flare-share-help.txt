Share a Markdown file

Each image that the Markdown shows by a relative path, such as img/chart.png, is uploaded with the file: at most 10 images, each a PNG, JPEG, GIF or WebP file of at most 5 MiB, and at most 4 MiB with the file in all, or it fails with flare::images::body_too_large. The server removes each image's metadata, its GPS position included, and keeps its orientation and colour profile. An image file that does not exist fails with flare::images::missing, and one outside the Markdown file's folder fails with flare::images::outside_folder.

Usage: flare share [OPTIONS] <FILE>

Arguments:
  <FILE>
          The file: .md or .html

Options:
      --title <TITLE>
          The title; without it, a Markdown file's first level-one heading, else the file name without its ending

      --with <WHO>
          Readers, comma-separated: addresses, team:<name>, everyone

      --re <ID>
          The flares it responds to, whose owners become Readers; repeated or comma-separated

      --update <ID>
          Publish the file as your share's next version
          
          It changes only the content; grants stay with flare grant.

      --dry-run
          Report what the command would change, and change nothing

      --out <PATH>
          With --dry-run, write the HTML here

      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  flare share review.md --with ana@example.org,jo@example.org
          Share review.md with two people

  flare share answer.md --re 3f9c0a17e2b44d6f8a1c5b7e9d20f4a6
          Share answer.md as a response to a flare

  flare share review.md --update 3f9c0a17e2b44d6f8a1c5b7e9d20f4a6
          Publish review.md as the next version of a share you own

  flare share review.md --dry-run --out review.html
          Check review.md as the server would and write its HTML to review.html, sharing nothing

Columns:
  id           The share's id; none on a dry run of a new share.
  title        The share's title; none on a dry run of `--update`, which does not read the share.
  version      The share's latest version; none on a dry run.
  granted      The addresses that now hold a role on it; none after `--update` or a dry run.
  responds_to  The flares it responds to; none after `--update` or a dry run.
  images       The images sent with the document; on a dry run, the images it would send.

Effects: additive, not idempotent, closed-world.
Children: A dry run lists its checks.
