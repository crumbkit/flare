Delete the image files that no version lists from the hosted site's bucket

Usage: flare files sweep [OPTIONS]

Options:
      --config <PATH>  The config file whose hosted.stores names the table and the bucket; without it, $XDG_CONFIG_HOME/flare/config.json or ~/.config/flare/config.json
      --yes            Proceed without asking for confirmation
  -h, --help           Print help (see more with '--help')

Examples:
  flare files sweep --config /etc/flare/config.json --yes

Effects: destructive, idempotent, closed-world.
Global flags: --json, --fields <FIELD>, --full, --no-input. `flare files sweep --help` describes them.
Next: flare files sweep --help explains each column.
