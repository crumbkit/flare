Search the shares you can open, newest first

Usage: flare search [OPTIONS] <QUERY>

Arguments:
  <QUERY>  The search, such as 'budget -type:html' or 'from:me "review notes"'

Options:
      --limit <N>  Print at most this many rows, up to 500 [default: 50]
      --all        Print every row
  -h, --help       Print help (see more with '--help')

Examples:
  flare search 'budget -type:html'
  flare search 'from:ana@example.org,me "review notes"' --limit 20

Effects: read-only, closed-world.
Global flags: --json, --fields <FIELD>, --full, --no-input. `flare search --help` describes them.
