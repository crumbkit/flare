Save a binding that fills a page's slots with records

Usage: flare bind [OPTIONS] --name <NAME> <PAGE> <SLOT=PATH>...

Arguments:
  <PAGE>
          The page the binding fills

  <SLOT=PATH>...
          Each slot and the record that fills it, as SLOT=PATH, separated by spaces

Options:
      --name <NAME>
          The binding's name, one segment of lowercase letters, digits and dashes

      --board <DIR>
          The board's directory; without it, the nearest directory at or above the current one that holds .board/board.json

      --board-program <PATH>
          The board program; without it, FLARE_BOARD, then the first board on PATH

      --dry-run
          Report what the command would change, and change nothing

      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  flare bind task-card --name kitchen task=/tasks/tap
          Save the binding kitchen, which fills task-card's task slot with /tasks/tap

Columns:
  name     The binding's name.
  page     The page the binding fills.
  version  The page version the binding is pinned to.

Effects: additive, not idempotent, closed-world.
Writes: applies all items or none.
