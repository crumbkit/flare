Publish a page version from an HTML or Markdown file

Usage: flare publish [OPTIONS] --name <NAME> <FILE>

Arguments:
  <FILE>
          The page's file: .html for HTML, .md for Markdown

Options:
      --name <NAME>
          The page's name, one segment of lowercase letters, digits and dashes

      --slots <FILE>
          A JSON file that lists the page's slots

      --board <DIR>
          The board's directory; without it, the nearest directory at or above the current one that holds .board/board.json

      --board-program <PATH>
          The board program; without it, FLARE_BOARD, then the first board on PATH

      --dry-run
          Report what the command would change, and change nothing

      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  flare publish card.html --name task-card --slots slots.json
          Publish card.html as the page task-card with the slots in slots.json

  flare publish card.md --name task-card --dry-run
          Check card.md and publish nothing

Columns:
  name     The page's name.
  version  The new version, or none on a dry run.
  format   The page's markup language: `html` or `markdown`.
  slots    The names of the page's slots.

Effects: additive, not idempotent, closed-world.
