Print the JSON Schema of each document

Usage: flare schemas show [OPTIONS] <ID>...

Arguments:
  <ID>...  The ids of the documents that `schemas list` lists, separated by spaces

Options:
  -h, --help  Print help (see more with '--help')

Examples:
  flare schemas show flare/shares/v1

Effects: read-only, closed-world.
Global flags: --json, --fields <FIELD>, --full, --no-input. `flare schemas show --help` describes them.
Next: flare schemas show --help explains each column.
