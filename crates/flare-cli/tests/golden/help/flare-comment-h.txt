Comment on a flare

Usage: flare comment [OPTIONS] <--body <TEXT>|--body-file <FILE>> <FLARE>

Arguments:
  <FLARE>  The flare to comment on

Options:
      --body <TEXT>       The text, 1 to 8,000 characters
      --body-file <FILE>  A file that holds the text, which is how to send more than one line
      --key <KEY>         The key that makes a repeat of this call write nothing; without it, a new random key
  -h, --help              Print help (see more with '--help')

Examples:
  flare comment 3f9c0a17e2b44d6f8a1c5b7e9d20f4a6 --body 'Is this final?'
  flare comment 3f9c0a17e2b44d6f8a1c5b7e9d20f4a6 --body-file note.txt --key note-1

Effects: additive, not idempotent, closed-world.
Global flags: --json, --fields <FIELD>, --full, --no-input. `flare comment --help` describes them.
